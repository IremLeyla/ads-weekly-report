# Arbeitsregeln für dieses Projekt

- Ich lerne mit diesem Projekt. Erkläre jeden Schritt kurz in einfacher Sprache, bevor du Code schreibst, und warte auf mein Okay bei größeren Entscheidungen.
- Halte den Code einfach: Python und pandas, wenige Dateien, gut kommentiert. Keine unnötigen Frameworks.
- Das LLM darf nur Zahlen aus der Tabelle der geprüften Werte verwenden. Nach jedem generierten Text prüft der Code, dass jede Zahl im Text in dieser Tabelle vorkommt. Schlägt die Prüfung fehl, wird der Text nicht verwendet.
- Unklare Ursachen werden als „unklar“ benannt, nie geraten.
- Meta-Käufe und Shopify-Bestellungen sind verschiedene Zahlen. Nie eine davon stillschweigend als „die richtige“ übernehmen, sondern den Unterschied zeigen.
- API-Schlüssel stehen nur in einer .env-Datei, die nie committet wird.
- Öffne TESTLOESUNG.md nicht. Die Datei ist nur für mich, um am Ende zu prüfen, ob der Report die Ereignisse in den Daten selbst findet.
